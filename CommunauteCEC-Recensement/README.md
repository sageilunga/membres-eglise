# Application de Recensement - Communauté CEC

Projet complet de recensement et de gestion des membres pour la Communauté CEC.

## Structure du Projet

- `backend/` : Serveur Node.js (Express) relié à la base de données Excel (`membres_eglise.xlsx`).
- `frontend/` : Interface Web moderne réactive sous React + Tailwind CSS (compatible Supabase & Vercel).

## Lancement Rapide

### 1. Démarrer le Backend (Serveur Excel)
```bash
cd backend
npm install
node server.js
```

### 2. Démarrer le Frontend (Interface React)
```bash
cd frontend
npm install
npm run dev
```
